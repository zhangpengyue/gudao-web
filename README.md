# 谷道 · 情绪与龙头

一个单文件的 A 股情绪周期 / 龙头梯队看板。手机上打开就能用，不需要安装、不需要后端、不需要构建。

> 纯个人交易工具，用于记录和执行自己的纪律，**不构成任何投资建议**。

## 能做什么

| 页签 | 内容 |
|---|---|
| **今日建议** | 五大指数实时多空 → 市场结构；涨停/跌停/炸板三池 → 情绪阶段；两者合成目标仓位区间与加减仓结论 |
| **看盘** | 市场总龙头（按连板数 + 封板时间排序）、题材龙头、强势首板、连板梯队健康度 |
| **自选** | 自选 ETF 的 MA20/MA60 趋势状态与加仓/减仓信号 |
| **持仓** | 实时盈亏、仓位占比、单票止损纪律检查（默认 -7%） |

## 怎么用

**直接在浏览器打开**：双击 `index.html`，或访问部署好的 Pages 地址。

**手机上添加到主屏幕**：用浏览器打开右上角菜单 → 「添加到主屏幕」，之后就像 App 一样全屏打开。

**第一次使用先填两个数**：进入「持仓」页，填写总资金和持仓成本。总资金没填之前，仓位建议会显示「待录入」，不会给你一个拍脑袋的加仓比例。

## 数据存在哪里

**只在你自己这台设备的浏览器里**（localStorage）。不上传、不联网同步、没有账号体系。

换手机或清理浏览器缓存会丢失，所以「持仓」页提供了导出/导入备份，建议填完后导出一份存起来。

## 数据来源

浏览器直接请求公开行情接口：

- 涨停 / 跌停 / 炸板池：东方财富 `push2ex.eastmoney.com`
- 指数、个股、ETF 实时价：腾讯 `qt.gtimg.cn`
- 日 K 线（算 MA20 / MA60）：腾讯 `web.ifzq.gtimg.cn`

这几个接口目前都返回 `Access-Control-Allow-Origin: *`，所以静态页面可以直接取数，不需要代理。**但这是数据源主动放开的，不是承诺** —— 哪天加了白名单，页面就会取不到数。

页面第 184 行有一个 `PROXY` 常量：

```js
const PROXY = "";   // 例：'https://xxx.workers.dev/?u='
```

留空是直连。真被封了，在这里填一个转发地址就能救回来，业务代码一行都不用改。

## 已知限制

- **涨停池的 `date` 参数无效**，接口永远返回最新快照。所以页面只显示接口返回的交易日（`qdate`），不做历史查询。
- **收不到主动推送**。破止损、情绪切换这些提醒只在页面打开且点「刷新」时才能看到。想要关掉页面也能收到提醒，需要后端常驻 + 推送通道。
- **没有跨设备同步**。想手机和电脑看到同一份持仓，需要账号体系。
- 行情接口有频率限制，别把自动刷新调到 1 分钟以内。

## 本地开发

没有依赖，没有构建步骤。直接编辑 `index.html` 里的 `<script>` 即可，改完刷新浏览器。

所有规则（情绪判定、目标仓位、龙头排序、止损纪律）都在 `index.html` 内的纯函数里，和 Python 桌面版逐条比对过，逻辑一致。
